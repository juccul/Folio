# Folio 0.1.8

- Review recognized writing shows the recognized text again. Its text field could collapse into a narrow empty strip; it now fills the dialog, so the result can be read and corrected before Copy text, Keep ink and make searchable, or Replace writing.
- Ctrl+V places a pasted image at the pointer, and Paste from the canvas menu places it where the menu opened. The image is selected straight away, ready to move or resize, on pages and infinite canvases; undo removes it in one step.
- On native Wayland, a pen now shows the system pointer over toolbars, menus and dialogs. The canvas keeps Folio's own pen cursor. This has not yet been validated with physical tablets.

Windows x64 setup EXE and portable ZIP, Linux x86_64 Flatpak, checksums and complete corresponding source are published together. Updates remain signed and user-initiated.

Database schema remains 6 and document format remains 4. See [UPDATES.md](UPDATES.md) for installation and recovery.
