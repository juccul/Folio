# Folio 0.1.1

- Compact writing toolbar with grouped pen, eraser, selection and insert controls. Page view/search and document controls retain their positions; export is in Document actions.
- Simpler Pen menu with separate settings and preset management. Built-in pen types remain default options; saved presets are user-defined. Unchanged generated presets are cleaned up without removing renamed or customized pens.
- Accurate color box and hue strip in both themes, stable colors during dragging, and previews that match the selected hex.
- Readability adjustment defaults off. Untouched default ink follows the paper/theme; custom colors stay fixed. Optional readability changes lightness minimally while preserving hue and saturation.
- Folder menus available through the three-dot button or right-click, folder and document drag-and-drop, and clearer sidebar hover states.
- Shorter rounded tab highlights and hover effects, improved titlebar spacing, and a centered “No documents” empty state.
- Distinct Solve and Recognise math icons; selection actions remain visible while the solver is open.
- Cached update offers clear after a signed check confirms there is no newer release.

Windows x64 setup EXE and portable ZIP, Linux x86_64 Flatpak, checksums and complete corresponding source are published together. Updates remain signed and user-initiated.

Database schema remains 6 and document format remains 4. See [UPDATES.md](UPDATES.md) for installation and recovery.
