# Folio 0.1.2

- Smoother Windows drawing on ink-heavy pages, with bounded background caching for settled ink.
- More reliable scribble erase for horizontal, vertical, diagonal and rounded scrubs. Erasing follows the swept area and includes nearby letter fragments and detached marks while protecting surrounding content.
- Smart shape previews stay snapped through small pen movements, including lifting the pen. Moving more than 16 screen pixels resumes regular ink, consistently at different zoom levels.

Windows x64 setup EXE and portable ZIP, Linux x86_64 Flatpak, checksums and complete corresponding source are published together. Updates remain signed and user-initiated.

Database schema remains 6 and document format remains 4. See [UPDATES.md](UPDATES.md) for installation and recovery.
